# Grocery Delivery App

## Overview

Grocery Delivery App is an Android application developed using Kotlin and Jetpack Compose. The app provides a simple grocery shopping experience with user authentication, product browsing, cart management, checkout, order tracking, profile management, and Firebase Firestore integration.

## Technologies Used

- Kotlin
- Android Studio
- Jetpack Compose
- Firebase Authentication
- Firebase Firestore

## Features

- User Registration and Login
- Home screen with grocery products
- Product details
- Quantity management
- Add to Cart
- Cart and total price calculation
- Checkout
- Delivery address management
- Payment method selection
- Order confirmation
- Order tracking
- Order History
- User Profile
- Logout
- Firebase Firestore data storage

## Firebase Integration

Firebase Authentication is used for user authentication.

Firebase Firestore is used to store:
- User details
- Orders
- Delivery addresses

## Project Structure

The main application screens are implemented using Jetpack Compose in `MainActivity.kt`.

## How to Run

1. Clone this repository.
2. Open the project in Android Studio.
3. Make sure `google-services.json` is available in the `app` folder.
4. Sync the Gradle files.
5. Run the application on an Android emulator or Android device.
